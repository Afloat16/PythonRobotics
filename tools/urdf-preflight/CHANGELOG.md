# Changelog

## 0.1.0 — 2026-09-30

Initial source release: bounded XML reader, selected URDF 1.0/1.1/1.2 checks, link/mimic graph diagnostics, complete inertia-tensor checks, local/package asset checks, text/JSON/SARIF/offline HTML reporting, explicit baselines and ignore rules, two original examples, standard-library tests and numerical cross-check script.

Read-only/offline checking is the default. No runtime dependencies, automatic parameter repair, Xacro execution, remote asset fetching, simulator compatibility guarantee or PyPI publication.
